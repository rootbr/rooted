# Research note — Python exceptions and context managers

Topic `python-exceptions-and-context-managers` of group python, domain `errors`, id prefix `PY`. Formulation locators: Ruff B, BLE, TRY, E7; Pylint; CPython errors tutorial, `contextlib`.

The catalogs check the shape of Python handlers (bare and blind except, handlers that reach BaseException, except clauses joined by or/and, handlers and tuple entries that an earlier or base class already catches), the semantics of raise (raise from inside except, a bare raise outside a handler, raise exc versus bare raise), the extent of the try block (Ruff TRY300, PLW0717, Pylint W0717, SIM105), custom exception classes (direct BaseException inheritance, an __init__ that drops args) and context managers (cleanup after the yield of a @contextmanager generator, an __exit__ that re-raises, resources opened without with). The documentation states the semantics behind them: PEP 8 Programming Recommendations (bare except, except Exception, raise X from Y, deriving from Exception, the minimal try), the CPython tutorial on errors (exception chaining, the else clause, BaseException and Exception), the language reference on the except clause, the else clause, the bare raise and __exit__, the exceptions page (SystemExit, KeyboardInterrupt, TypeError versus ValueError, BaseException) and contextlib.contextmanager. Positions differ in four places: PEP 8 tolerates a bare except whose handler prints or logs the traceback, while Sonar S5754 and bugbear B036 require the re-raise in every case; PEP 8 reserves direct BaseException inheritance for exceptions that should almost never be caught, while Sonar S5709 forbids it; Ruff EM101-EM103 move message literals out of the raise, while the tutorial writes them inside the constructor; Ruff SIM105 prefers contextlib.suppress but names its performance cost. Ten rules are carded, two candidates are instances of ERR-07 and ERR-27, nine fold into the carded rules, eight are held by the cap and one is pending. The relayed papers (arXiv:2602.05123, Exception Miner SBES, arXiv:1704.00778) measure how often exceptions and handling anti-patterns occur but state none of the carded rules, so none is cited. The raw path Doc/library/exceptions.rst answered 404 on the cpython main and 3.13 branches, so that page is cited from docs.python.org.
