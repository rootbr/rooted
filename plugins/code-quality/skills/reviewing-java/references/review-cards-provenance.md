# Review-cards provenance map

Out-of-runtime maintainer record. The review workflow does **not** pass this file to a finder — a card carries the rule, its numbers and a compact `## Source` locator; this map carries the full citation, the origin section in the source checklist, the formulation source where a practitioner text supplied the wording, and the maintenance notes. Round-trip rule: a card plus its line here reconstruct everything known about the rule.

One line per card: `rule_id · source (full citation, with the fetched form where it differs from the canonical URL) · origin section(s) · formulation source · notes` (evidence strength, ownership, caveats). The origin checklists left the tree once carded; git history preserves them under `agents/<domain>-reviewer/references/checklist.md`.

Verification channel: a JDK Javadoc citation is verified against the class source at `github.com/openjdk/jdk`, tag `jdk-21-ga`, whose doc comments are the text the published Java SE 21 API pages render; a jcstress citation against `github.com/openjdk/jcstress`; an OWASP, Spring, Hibernate or Jakarta citation against the project's documentation source on GitHub. A citation marked **unfetched** names a canonical page that could not be opened from the authoring environment and was cited as its provenance line anchors it; it is openable by any reader and stands to be re-verified.
