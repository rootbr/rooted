# Provenance of the committing-changes rules

Maintainer record, read in no run. One line per rule of `SKILL.md`, keyed by its section and position; the run set states the rule alone, and a rule and its line here change together. A line names the document or practice the rule comes from, then the tests and documents found for it, then its record in the format of `plugins/evidence-based-authoring/skills/scientific-method/references/record-format.md`: a norm with the document opened, or the owner's decision, whose claim waits as `H-<id>` in `pending-evidence.md`. `citations.json` holds the words and figures the lines quote from their sources, one entry per quote.
