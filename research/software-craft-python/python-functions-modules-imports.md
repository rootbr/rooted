# Research note — Python functions, modules and imports

Topic `python-functions-modules-imports` of group python, domain `design`, id prefix `PY`. Formulation locators: Ruff PLR, F, E4, TID, INP; Pylint; PEP 8 imports; pyguide.

The catalogs check import form and placement (Ruff F403/F405, E402, PLC0415, TID252, TID255, INP001, RUF067, RUF068, PLC0414; Pylint W0401, W0614, C0413, C0415, C0414; Sonar S2208, S7941), rebinding by def, class and import (Ruff F811; Pylint W0404, W0416), argument kinds (Ruff FBT001-003, PLR0917, B026; Pylint R0917, W1113, W1117), the global statement (Ruff PLW0602-0604; Pylint W0601-0604), shadowing of builtins and stdlib modules (Ruff A001-A006), lambda assignment (Ruff E731, Pylint C3001, Sonar S6661), the exit and quit builtins (Ruff PLR1722, Pylint R1722) and os.environ rebinding (Ruff and flake8-bugbear B003). PEP 8 §Imports and §Programming Recommendations, the Google style guide and the CPython reference and tutorial state the semantics behind them: import and def are executable bindings, a star import binds every public name of the other module, the script directory precedes the standard library on sys.path, the site module adds exit and quit for the interactive shell only, modifying os.environ calls putenv, and a bare * makes the following parameters keyword-only. Positions differ on imports inside functions (Pylint moves every one to the top; Ruff names circular dependencies, costly loads and optional dependencies as reasons), on relative imports (PEP 8 accepts explicit relative imports, the Google guide forbids them, Ruff bans parent-relative ones by default), on code in __init__.py (Ruff RUF067 flags it, the tutorial lets __init__.py run package initialization) and on wildcard imports for re-export (PEP 8 allows republishing an internal interface, Sonar exempts __init__.py). Rebinding module state through global is DSN-63's Python instance.
