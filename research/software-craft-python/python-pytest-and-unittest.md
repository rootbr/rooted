# Research note — Python pytest and unittest

Topic `python-pytest-and-unittest` of group python, domain `tests`, id prefix `PY`. Formulation locators: Ruff PT; pytest docs; Pylint.

The catalogs for this topic are Ruff's flake8-pytest-style rules (PT008, PT009, PT014, PT019, PT021, PT022, PT025-PT031) with RUF043, RUF061, PGH005 and the preview pytest-fixture-autouse, and SonarSource's pytest rules (S5906, S8714, S8998-S9136); no Pylint entry reached this topic. They check the form of pytest's checking APIs (pytest.raises, pytest.warns and pytest.deprecated_call as context managers, match= as a regular expression, the warning category and the size of a pytest.warns block), fixture injection and form (defaulted parameters, yield against request.addfinalizer, yield without teardown, marks and usefixtures on fixtures, an unused fixture parameter, a restated default scope), parametrize argvalues (repeated and empty rows) and unittest.mock usage (a bare or misspelled assertion method, patch with a constant lambda). The pytest source docstrings and reference and how-to pages state the mechanisms behind them: match is applied with re.search, pytest.warns defaults expected_warning to Warning, getfuncargnames skips parameters with defaults, empty_parameter_set_mark defaults to skip, duplicate parameter-set IDs are made unique by suffixes, and a mark on a fixture was deprecated in 7.4 and removed in 9.0; the CPython unittest.mock page states Mock's unsafe-prefix check and what patch puts in place when new is omitted. Positions differ in four places: Ruff PT029 says pytest.warns() fails at run time while the pytest source defaults the category to Warning; SonarSource S9136's typo example assert_called_wit is rejected by Mock since Python 3.5; SonarSource S9000 calls the pytest.raises callable form deprecated while the pytest docstring still documents it; and pytest documents pytest_plugins in a test module while SonarSource S8999 flags it. Ten cards ship, ten candidates fold into them or into held rules, four are instances of TST-18, TST-20 and TST-23, five are held for the cap and one is pending a separating condition.
