# Provenance of the subtopic-discovery methods

One line per source reference behind a method of the run set — `references/methodology-inventory.md` and the method prompts `agents/method-NN-*/prompt.md` — keyed by method and sub-technique, so that the run-set text and its provenance line together carry everything known. Each line holds the citation as it stood in the run-set text, then where it stood, then the tests and documents found for the technique, then its record in the format of `../../scientific-method/references/record-format.md`. A technique whose claim waits for its test is its owner's decision, and its record names the claim as `H-<id>` in `pending-evidence.md`; `citations.json` holds the words and figures the lines quote from their sources, one entry per quote. In a citation, a method name that stays in the run set (Zwicky box, Munger-Jacobi inversion, Six Thinking Hats, structure-mapping, Meadows' leverage points) is the technique's name, not its citation.
