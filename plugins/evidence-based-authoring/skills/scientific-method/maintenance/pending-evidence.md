# Hypotheses about the method

The claims about the method itself that no test backs yet, keyed `H-n`. Each names its measure and the outcome that would refute it; a hypothesis whose test is planned as our own also names its threshold, its runs and the file that holds the test, and is committed here before the test runs. A hypothesis that a test settles keeps its line, with the result and the new standing.
