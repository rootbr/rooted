# Provenance of the subtopic-discovery methods

One line per source reference behind a method of the run set — `references/methodology-inventory.md` and the method prompts `agents/method-NN-*/prompt.md` — keyed by method and sub-technique, so that the run-set text and its provenance line together carry everything known. Each line holds the citation as it stood in the run-set text, then where it stood; a method name that stays in the run set (Zwicky box, Munger-Jacobi inversion, Six Thinking Hats, structure-mapping, Meadows' leverage points) is the technique's name, not its citation.

## method-01 Structural decomposition

- **method-01 Starbursting (5W1H)** · Kipling, *Just So Stories* (1902) — "six honest serving-men", the primary lineage; modern form popularized in creative-problem-solving literature (see Mindtools, *Starbursting*, https://www.mindtools.com/ab1w9zu/starbursting/) · inventory §1, prompt method-01.
- **method-01 Morphological analysis (Zwicky box)** · Zwicky, 1969, *Discovery, Invention, Research — Through the Morphological Approach* (Macmillan), https://www.swemorph.com/pdf/gma.pdf · inventory §1, prompt method-01.
- **method-01 SCAMPER** · Eberle, B. (1971). *SCAMPER: Games for Imagination Development*; rooted in Osborn's *Applied Imagination* (1953) checklist questions · inventory §1, prompt method-01.
- **method-01 SCAMPER Eliminate as the highest-yield transformation; G-02** · house heuristic; no external source, not verified by a measured run.
- **method-01 length targets (quick 20–30 / standard 30–50 / deep 50–80) and the per-vector counts** · house defaults; no external source, not verified by a measured run.
