# Maintenance of `committing-changes`

Nothing under `maintenance/` is read in a run. `rules-provenance.md` holds the source of every rule of `SKILL.md`, keyed by section and position, so a rule and its provenance line change together; each line closes with the record of what the rule rests on, in the format of the skill `scientific-method` of the plugin `evidence-based-authoring` (`references/record-format.md`). The claims that wait for a test stand in `pending-evidence.md` with the published sources found beside them so far, and the quoted words of both files stand in `citations.json`, which `check_quotes.py` of that skill's `maintenance/scripts/` checks against their sources. The run set is `SKILL.md` alone, listed in the skill's `README.md` §Layout.
