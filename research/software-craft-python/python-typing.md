# Research note — Python typing

Topic `python-typing` of group python, domain `code`, id prefix `PY`. Formulation locators: Ruff ANN, TC, UP; typing spec; mypy docs; PEP 484, 544, 589, 695.

Python typing as the catalogs check it: Ruff flake8-annotations (ANN001-ANN206) and SonarSource S6538/S6540 require parameter and return annotations. Ruff pyupgrade (UP006, UP007, UP045, UP040, UP046, UP047, UP052), Pylint's typing checker (W6001, R6002, R6003) and SonarSource (S6545, S6546, S6792-S6796) move annotations to the syntax of the project's minimum Python: PEP 585 builtin generics from 3.9, PEP 604 unions from 3.10, PEP 695 type parameters and the type statement from 3.12. Ruff flake8-type-checking (TC001-TC010) and flake8-future-annotations (FA100, FA102) guard the line between annotations and code that runs. The CPython typing documentation deprecates the typing aliases of builtin collections as of 3.9 without a runtime warning, recommends the int | str shorthand, deprecates TypeAlias as of 3.12 and states that TYPE_CHECKING is False at run time. The mypy documentation states that by default mypy does not type check the body of an unannotated function, and that an evaluated int | str raises TypeError before 3.10. os.getenv returns a str, or the default unchanged. Positions differ in three places. First, the Google Python style guide requires annotations on public APIs and leaves the rest to judgment, while Ruff ANN and Sonar flag every function; public API and the project's checker settings separate the cases. Second, the guide still shows a TypeAlias annotation and a module-level TypeVar where Ruff and Sonar require PEP 695 syntax; a minimum Python of 3.12 separates them. Third, the guide discourages TYPE_CHECKING-only imports except where an import must be avoided at run time, while Ruff TC001-TC003 move every typing-only import; an import cycle or a costly import separates them, and a hunk does not show either. Ten cards ship and six candidates fold into them. Seven candidates are held at the cap and one is held as not checkable on a diff.
