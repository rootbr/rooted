# LLM-self-authored context must be audited, not assumed

## Thesis
Auto-generated CLAUDE.md / AGENTS.md / SKILL.md produced by an LLM regresses, so its provenance must be audited. Where a file declares "auto-generated", "produced by LLM", or "generated from <code>/<config>", flag for deletion or a human-author audit pass. Where the style looks LLM-generated but carries no provenance marker, flag as suspect.

## Rationale
Self-authored context consumes the same token budget as audited context while measurably reducing success: auto-generated agent files cost +20–23% inference cost for −0.5% to −2% success, and self-generated SKILL.md lands below the no-Skills baseline on every tested configuration (−8.1 to −11.5pp) while curated Skills add +18.2 to +24.8pp on the same configurations. Provenance must therefore be audited rather than assumed.

## Example
```
bad:  "## Best Practices — It is important to always ensure code is clean
       and maintainable." (uniform, hedged, no examples, no source)
good: human-authored section with a concrete failure mode and a cited number
```

## Limits
The output of a verification-gated optimizer loop — bounded edits accepted only on held-out validation improvement — is not ungated self-authoring; there, audit the gate's existence, not provenance alone. A single weak signal is not enough; three or more medium style signals are required before flagging on style.

## Validator
Score style signals: explicit "generated by" marker (strong); every section the same paragraph length, hedging openers ("It is important to", "Make sure to"), abstractions without examples or numbers, no source citations anywhere (each medium); generic section names with no domain specificity (weak). An explicit marker flags directly; otherwise three or more medium signals flag. Run once across the file, at most one patch per section.

## Patch output
When a provenance marker or three or more medium style signals indicate self-authoring, emit one patch (`rule_id: R-52`, `location.section` = whole file or specific section, severity medium) proposing deletion or human rewrite validated by a fresh agent on real tasks; set `needs_human: true` because confirming authorship is a judgement call.
