# Research note — Python strings, bytes, paths and I/O

Topic `python-strings-bytes-paths-io` of group python, domain `code`, id prefix `PY`. Formulation locators: Ruff PTH, UP, ISC, FURB, PLR, RUF; CPython io, pathlib, re.

The 38 candidates of Python strings, bytes, paths and I/O come mostly from Ruff (ISC, PTH, UP, FURB, RUF, DTZ, B, F), Pylint's W13xx/W14xx string checks and SonarSource python, and the CPython reference (string literal concatenation, escape sequences, f-strings), the re, datetime, os.path, pathlib and string pages state the semantics behind them. Ten rules are carded in shipping order: silent concatenation of adjacent literals, unrecognised escapes (SyntaxWarning since 3.12), naive utcnow/utcfromtimestamp (deprecated 3.12), positional count/flags to re.sub/subn/split (deprecated 3.13), surplus arguments that % and str.format drop silently, raw-string regex patterns, f-strings over % and str.format outside logging, pathlib over os.path, 0o-prefixed permission modes and commonpath over commonprefix (deprecated 3.15). Positions differ only on pathlib, where Ruff's own known issue and the pathlib page keep os.path for measured hot spots and low-level string handling. open() without with is a universal instance of ERR-27, the naive-datetime family of TOOL-43, and the strftime %I/%p rule is not Python-specific; twenty-one idiom or narrow-reach candidates are held at the cap, four fold into carded or held rules. The datetime candidates sit in this topic by triage, outside its owned list.
