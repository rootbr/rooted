# Research note — Python collections and iteration

Topic `python-collections-and-iteration` of group python, domain `performance`, id prefix `PY`. Formulation locators: Ruff C4, PERF, PLC, SIM, RUF; CPython itertools.

The catalogs check this topic as idioms of the dict, set and list API, of iteration helpers (zip, map, enumerate, itertools) and of the generator protocol: Ruff's C4, PERF, PLC/PLE/PLR, SIM, FURB, RUF and B9xx rules, Pylint's refactoring and convention messages, SonarSource's S75xx-S95xx Python rules and flake8-bugbear. The CPython documentation states the semantics behind the ten carded defects directly: iterating a dict yields its keys (stdtypes), zip and map stop at the shortest input and the zip entry recommends strict=True (functions, PEP 618), dict.fromkeys stores one value object under every key (stdtypes), groupby groups share the source iterator (itertools), a StopIteration leaving a generator becomes RuntimeError (PEP 479, exceptions), in-place collection methods return None (stdtypes, design FAQ), defaultdict keyword arguments become entries (collections), a dict display or comprehension keeps the last value of a repeated key (reference, expressions) and sum points to itertools.chain for concatenating iterables (functions). Eight cards are silent-correctness rules and two are cost rules whose cost the catalogs measure or bound (list comprehension into any/all, sum over lists, the latter a Python-specific extension of PRF-17 because sum hides the copying loop). The remaining candidates are micro-idioms (dict.get, set.discard, enumerate, yield from, redundant conversions, literal forms) held by the cap at minor or suggestion severity, with their catalog entries folded so a later run takes one rule per check. Positions differ in three places: Ruff's FURB140 recommends itertools.starmap for readability and speed while its own Known problems section says starmap is slower than comprehensions since Python 3.12 (PEP 709), so it stays pending; Ruff marks PLR6201's set-literal rewrite unsafe for unhashable elements; and Ruff marks UP028's yield-from rewrite unsafe where send() reaches an iterator without it. Ruff states PERF101 is negligible in most cases. The two relayed arXiv papers (2301.12633, 2203.14484) measure nine idioms in aggregate and back no carded claim. Note for later runs: CPython main now keeps stdtypes.rst, functions.rst and exceptions.rst under Doc/builtins/; the Doc/library/ raw paths return 404 for them.
